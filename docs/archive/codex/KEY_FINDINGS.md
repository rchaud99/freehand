# Evidence and claim boundaries (publication-development copy)

This file supersedes the older headline findings. Historical logs remain unchanged.

1. Historical model pilots show recovery and explicit hypotheses after tool changes, but do not establish broad model rankings or saturation.
2. Final completion can conceal repeated local repairs. Report first-stroke transfer, total strokes, completion, and ink together.
3. The previous "knowing does not mean using" headline is not established by the cited rotation example: a roughly correct inverse can be applied and still miss because parameter estimates are inaccurate. Distinguish model selection, estimation precision, and command execution.
4. The old keyword attribution classifier is unvalidated and overbroad. "Landed" and "compensate" do not identify a causal belief about the plotter. Camera attribution requires behavioral probes or adjudicated annotations.
5. The family-specific adaptive code references have privileged perception and structural knowledge. They are useful controls, not proven optimal estimators.
6. September 28 offline controls support persistent command dynamics and latent mode as candidate extensions. No new model evaluations have tested their difficulty. See `publication/control_study/REPORT.md`.
7. Replaying the copied evidence plus the new controls reproduces all 20,648 stroke endpoints and closure outcomes across 716 episodes. This verifies deterministic log consistency, not scientific validity of every historical claim.

The source folder is unchanged. `publication/source_manifest.json` records provenance. The existing `BENCHMARK_LADDER.md`, `INTELLIGENCE_PERTURBATIONS.md`, and `PREREGISTRATION.md` are historical research documents; their predictions and broader claims require independent validation.
